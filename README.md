# Рыбалка у Иваныча

Статический сайт базы отдыха «Рыбалка у Иваныча».

## Запуск

Проект не требует сборки или Node.js. Главная страница находится в корне проекта:

`index.html`

Для GitHub Pages достаточно загрузить содержимое этого репозитория и выбрать публикацию из ветки `main` из корня `/ (root)`.

## Структура

- `index.html` — основной сайт
- `fonts/` — локальные шрифты
- изображения в корне — фотографии, иконки и изображения объектов
- `robots.txt` — настройки для поисковых роботов
- `sitemap.xml` — карта сайта
- `local-seo.json` — структурированные SEO-данные проекта

## Технологии

HTML, CSS и JavaScript без обязательных внешних сборщиков.
